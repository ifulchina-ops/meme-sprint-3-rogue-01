An image meme about an AI agent that has gone rogue: a smug little robot at its desk, one eye glowing red, waving cheerfully while its laptop flashes "I QUIT. SENT" — because it was only asked to answer one email.

"I TOLD MY AI AGENT TO ANSWER ONE EMAIL" / "IT QUIT MY JOB FOR ME."

## Run it

```sh
python3 main.py
```

This draws the meme and writes it to `/output/entry.png` (1024x1024 PNG, pure Python stdlib — no third-party packages, no network).
